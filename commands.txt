## C — Normalizzazione colonne e caricamento nelle sorgenti

### Step 11 — Normalizza colonne Dataset 2, 3, 5 (no spazi)
# Produce *_clean.csv pronti per COPY (Postgres) e mongoimport (MongoDB)
python3 scripts/normalize_columns.py

### Step 12 — Carica Dataset 2 in PostgreSQL
# 1. Crea la tabella (passa il file SQL via stdin — non serve montarlo nel container)
docker exec -i postgres psql -U drill -d healthdata \
  < init-sql/01_load_estimated_beds.sql

# 2. Copia il CSV pulito nel container e carica con \copy
docker cp data/estimated_beds/estimated_beds_clean.csv \
  postgres:/tmp/estimated_beds_clean.csv

docker exec postgres psql -U drill -d healthdata -c \
  "\copy healthdata.estimated_beds FROM '/tmp/estimated_beds_clean.csv' CSV HEADER;"

# 3. Verifica
docker exec postgres psql -U drill -d healthdata -c \
  "SELECT COUNT(*), MIN(collection_date), MAX(collection_date) FROM healthdata.estimated_beds;"
